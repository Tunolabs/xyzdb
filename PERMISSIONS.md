# Additional permissions

The Additional Use Grant in the `LICENSE` file allows the Licensor to publish
additional permissions that **broaden** it. Those permissions are published in
this file, or on the licensing page at xyzdb.bar.

Two rules govern this file:

- An additional permission takes effect for the versions it names as soon as it
  is published in either place.
- Once published, an additional permission is **not withdrawn**. It may be
  broadened further; it is never narrowed.

## Current permissions

**None.** No additional permissions have been published for any version of
xyzDB. The Additional Use Grant in the `LICENSE` file of the version you are
using is the complete statement of what is permitted without a commercial
license.

If your use is not permitted by that grant, or you are not sure, write to
licensing@tuno.bar. Asking costs nothing and we would rather answer than have
you guess.
